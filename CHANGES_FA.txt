وضعیت اندازه‌گذاری فلت پترن
===========================

1) solidworks/flat_view.py
   تابع FlatPatternView.draw شامل اندازه طول و عرض کلی و اندازه‌گذاری هر خط خم
   تا نزدیک‌ترین لبه بیرونی است. این مسیر برای PDF ساخته‌شده با ReportLab است.

2) solidworks/sw_drawings.py
   خروجی Native SLDDRW از SwDrawingPdfExporter ساخته می‌شود. تابع
   _insert_dimensions در این نسخه فقط InsertModelAnnotations3 را اجرا می‌کند؛
   این فراخوانی تضمین نمی‌کند که اندازه‌های سفارشی فاصله خطوط خم تا لبه درج شوند.

3) بنابراین این پروژه هنوز نسخه نهاییِ دارای اندازه‌های واقعی و قابل ویرایشِ
   خط خم تا نزدیک‌ترین لبه در خود SLDDRW نیست. PDF خروجی native از همان SLDDRW
   گرفته می‌شود، اما این ابعاد سفارشی تا زمان پیاده‌سازی و آزمون انتخاب هندسه
   و درج Dimension از طریق API خود SolidWorks تضمین‌شده نیستند.

4) فایل JSON ارائه‌شده به‌تنهایی برای اندازه‌گذاری مستقیم کافی نیست: محدوده
   outline در محور Y حدود -0.354 تا 0.654 است، درحالی‌که بعضی خطوط خم تا حدود
   +/-1.044 امتداد دارند. قبل از استفاده از این مختصات باید تبدیل دستگاه مختصات
   واقعی نمای SolidWorks اعمال شود؛ استفاده مستقیم از آن‌ها ابعاد اشتباه می‌دهد.
